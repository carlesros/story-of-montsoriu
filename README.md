# The Story of Montsoriu

A website narrating the real-life adventures and journey of Montsoriu, a little cat with a big heart.

Named in honor of the historic Castle of Montsoriu (Castell de Montsoriu), Catalonia, where our paths crossed on my walk down from the fortress.

Published at https://montsoriu.com

## Running the website locally

To run this website locally, you'll need to use **Node.js** and **npm**.

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run the Development Server**:
    ```bash
    npm run start
    ```

3.  **Access the Site**:
    Open your browser and navigate to `http://localhost:8080`.
